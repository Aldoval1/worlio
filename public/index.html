WebGPU no disponible

Tu navegador o tarjeta gráfica no tiene soporte para la API de WebGPU activado en este momento.

Cómo habilitar WebGPU:

  • Google Chrome / Brave / Edge: Asegúrate de usar una versión actualizada (113+) y tener activada la aceleración de hardware en Configuración > Sistema.
  • macOS Safari: Safari 18+ o en menú Desarrollo > Feature Flags > WebGPU.
  • Firefox: Escribe about:config y activa dom.webgpu.enabled.
